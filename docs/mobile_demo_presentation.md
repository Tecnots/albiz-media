# Albiz Media Mobile App: Comprehensive "A to Z" Demo Script

This document provides an exhaustive, step-by-step presentation script covering every corner of the Albiz Media mobile application. This is designed for a deep-dive technical and functional showcase, explicitly highlighting how the mobile experience interacts with our web-based Admin and Author teams.

---

## 1. Introduction & Mobile Architecture
**Speaker Script:**
> "Welcome to the full, end-to-end demo of Albiz Media. Our mobile app provides the rich experience of a native application while leveraging our powerful web infrastructure. 
> 
> Under the hood, this is an iOS/Android native app built via **Capacitor 8**. It runs a WebView pointed directly at our production Next.js application. Our entire backend is powered by **Supabase PostgreSQL** and the **Prisma ORM**.
> 
> A crucial concept to understand before we begin: While the mobile app serves **Anonymous, Normal, and Circle** users, it is deeply connected to our web platform where **Admins and Authors** operate. Throughout this demo, I will highlight exactly how actions taken by Admins and Authors on the web dictate the content and permissions you see here on mobile."

---

## 2. Onboarding & Authentication
**Speaker Script:**
> "Let's start with how users get into the app."

* **UI Description:** The welcome screen with Email/Password and 'Continue with Google' options.
* **User Flow:** A new user signs up, verifies their email, and sets their content preferences.
* **Data Flow (Cross-Platform Connection):**
  * **Sign Up/Login:** Hits the Next.js API route (`/api/auth/login`). 
  * **Role Assignment:** By default, new mobile users are assigned the `NORMAL` role. However, if our **Admins** on the web dashboard decide a user violates community guidelines, they can toggle a ban flag. The next time the mobile user's JWT session is checked, the app will instantly log them out or restrict their access based on the Admin's web action.

---

## 3. The Home Feed & The "X-Algorithm"
**Speaker Script:**
> "Once inside, the user lands on the Home Feed. This feed isn't just generated by algorithms; it is actively curated by our web teams."

* **UI Description:** A dynamic feed featuring horizontal category tabs (For You, News, Tech, Business). Users see a mix of user posts, rich-text articles, and official news.
* **User Flow:** The user scrolls through the feed, seeing "Featured" badges on certain posts and professional news articles in their stream.
* **Data Flow (Cross-Platform Connection):**
  * **Feed Generation:** Calls `/api/feed`. The backend runs the X-Algorithm to calculate relevance.
  * **Author Content:** You will notice professional, long-form 'News' articles. These cannot be created on mobile. They are drafted and published exclusively by users with the **AUTHOR** role using our advanced web-based publishing dashboard. Mobile users are the primary consumers of this rich Author content.
  * **Admin Curation:** If a mobile user's post goes viral, an **Admin** on the web panel can click "Feature" or "Pin". This updates the `featured` or `pinned` boolean in the `Post` table. When the mobile app fetches the feed, those posts are forcefully injected at the top of the mobile UI.

---

## 4. Rich Interactions & Content Moderation
**Speaker Script:**
> "Let's look at how mobile users interact with content and how our web Admins keep the platform safe."

* **UI Description:** Like, Comment, Share, and a "More" menu with options like "Flag/Report".
* **User Flow:** A user spots an inappropriate post and flags it. 
* **Data Flow (Cross-Platform Connection):**
  * **Reporting:** When the mobile user flags a post, the app updates the `flagged` boolean on the `Post` table.
  * **Admin Review:** This instantly pushes the post into the **Admin** moderation queue on the web dashboard. The Admin reviews the content and can delete the post or issue a warning. Once deleted by the Admin, the post disappears in real-time from all mobile feeds.

---

## 5. Shorts & Ephemeral Stories
**Speaker Script:**
> "For rapid, engaging content, we have Shorts."

* **UI Description:** Vertical, full-screen cards with text overlays.
* **User Flow:** User taps a circle at the top of the feed to view Shorts.
* **Data Flow:**
  * Fetches from the `Story` table. Mobile users generate these using their cameras, and the images are stored in Azure Blob Storage. Views and likes are tracked in real-time.

---

## 6. Explore & Discovery
**Speaker Script:**
> "If users want to branch out, they head to the Explore tab."

* **UI Description:** Trending topics, top creators, and categorized user directories.
* **User Flow:** The user browses the top trending content.
* **Data Flow (Cross-Platform Connection):**
  * The `/api/explore/trending` endpoint queries posts sorted by a custom engagement formula.
  * **Author Suggestions:** If a normal mobile user consistently posts high-quality content that trends here, an **Admin** using the web dashboard might notice them. The Admin can send an `AuthorSuggestion` to invite the mobile user to become an official web **Author**.

---

## 7. The Exclusive "Circle" Premium Community
**Speaker Script:**
> "One of our most unique features is 'Circle'—a vetted, premium tier for professionals. This is where the mobile and web platforms interact most heavily."

* **UI Description:** A dedicated tab with a gold/premium aesthetic. Non-members see a 'Request to Join' workflow.
* **User Flow:** A normal user applies to join, uploading their credentials (e.g., a LinkedIn profile or business ID). They are put in a "Pending" state.
* **Data Flow (Cross-Platform Connection):**
  * **Application:** Users submit professional details via `/api/circle/upgrade`. This creates a `CircleUpgradeRequest` in the database, and documents are uploaded to Azure.
  * **Admin Approval:** The mobile user *cannot* access the Circle yet. An **Admin** logs into the web dashboard, reviews the uploaded documents, and clicks "Approve". 
  * **Access Granted:** The Admin's action updates the user's role in the `User` table to `CIRCLE`. The next time the mobile user refreshes the app, their UI unlocks, granting them access to the exclusive `CirclePost` feed and member directory.

---

## 8. Secure Messaging & Social Inbox
**Speaker Script:**
> "Networking happens in the DMs. Let's look at Messages."

* **UI Description:** A real-time chat interface showing typing indicators, file attachments, and End-to-End Encryption toggles.
* **User Flow:** User starts an encrypted chat with a fellow Circle member.
* **Data Flow:**
  * Attachments upload to Azure. End-to-End Encryption uses the recipient's public key (stored in the `User` table) to encrypt the message on the client device. The encrypted string and initialization vector (`iv`) are stored safely in PostgreSQL.

---

## 9. Comprehensive User Profiles
**Speaker Script:**
> "Every user gets a highly customizable Profile page."

* **UI Description:** A sleek page showing Avatar, Bio, Experience, Education, and custom domains.
* **User Flow:** The user edits their profile and links a custom domain.
* **Data Flow:**
  * Aggregates modular profile tables. Custom domain mapping calls Vercel/Cloudflare APIs to provision hostnames seamlessly.

---

## 10. Saved Collections & Analytics
**Speaker Script:**
> "Finally, let's look at how users manage content and track their success."

* **UI Description:** Dynamic charts showing Audience Reach and Post Impressions over time.
* **User Flow:** A creator checks their dashboard to see how their post performed.
* **Data Flow:**
  * Uses PostgreSQL aggregation to group `PostImpression` records by timestamp to generate sparklines.
